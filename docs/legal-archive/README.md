## Versioning policy

1. Use `YYYY-MM-DD` as the legal version identifier.
2. Before editing a current legal document, copy it into the archive directory for its existing version.
3. Do not overwrite or delete archived versions.
4. Update both `LegalConsentGate.jsx` files whenever the current version changes.
5. Keep the visible document version and the Supabase consent version identical.
6. A new legal version requires fresh consent from users because the local-storage key and database query include the version values.
